Practical 08

Page Replacement
Algorithms

Aim

To simulate Page Replacement Algorithms like FIFO, LRU and Optimal in Operating System.

Theory

Page Replacement Algorithms are used in Operating Systems during Virtual Memory Management.

When a page fault occurs and all memory frames are occupied, the Operating System must decide which page should be removed from memory so that the required page can be loaded.

Different page replacement algorithms use different strategies to minimize page faults and improve system performance.

FIFO Algorithm

FIFO stands for First In First Out.

FIFO is the simplest page replacement algorithm. It replaces the page that has been in memory for the longest time.

The page that entered memory first is removed first.

Working of FIFO Algorithm:

  • Pages are loaded into memory in order of arrival.
  • When memory becomes full, the oldest page is removed.
  • A queue is maintained to track page order.

FIFO Program


#include <stdio.h>

int main()
{
    int frames[3];

    int pages[] = {1, 3, 0, 3, 5, 6, 3};

    int n = 7;

    int f = 3;

    int i, j;

    int k = 0;

    int pageFaults = 0;

    int found;

    for(i = 0; i < f; i++)
    {
        frames[i] = -1;
    }

    for(i = 0; i < n; i++)
    {
        found = 0;

        for(j = 0; j < f; j++)
        {
            if(frames[j] == pages[i])
            {
                found = 1;

                break;
            }
        }

        if(!found)
        {
            frames[k] = pages[i];

            k = (k + 1) % f;

            pageFaults++;
        }

        printf("After page %d: ",
        pages[i]);

        for(j = 0; j < f; j++)
        {
            if(frames[j] != -1)
            {
                printf("%d ", frames[j]);
            }

            else
            {
                printf("- ");
            }
        }

        printf("\\n");
    }

    printf("\\nTotal Page Faults = %d\\n",
    pageFaults);

    return 0;
}

LRU Algorithm

LRU stands for Least Recently Used.

LRU replaces the page that has not been used for the longest period of time.

It assumes that pages used recently are likely to be used again soon.

Working of LRU Algorithm:

  • Track recent usage of pages in memory.
  • Find the least recently used page.
  • Replace that page with the new page.

Optimal Algorithm

Optimal Page Replacement replaces the page that will not be used for the longest time in future.

It gives the minimum possible page faults among all algorithms.

Working of Optimal Algorithm:

  • Check future page references.
  • Find the page whose next use is farthest away.
  • Replace that page.

Output

Conclusion

Thus the FIFO Page Replacement Algorithm was implemented successfully.

FIFO, LRU and Optimal are important page replacement techniques used in Virtual Memory Management to reduce page faults and improve system performance.
