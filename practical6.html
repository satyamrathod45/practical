Practical 06

Reader Writer
Problem using
Semaphores

Aim

To write a program that solves the Reader Writer Problem using Semaphores in Operating System.

Theory

The Reader Writer Problem is a classical synchronization problem in Operating Systems.

It deals with controlling access to a shared resource when multiple processes execute simultaneously.

In this problem there are two types of processes:

  • Readers → Only read shared data.
  • Writers → Modify shared data.

The main objective is to allow multiple readers to access the shared resource at the same time while ensuring that only one writer can access the resource exclusively.

Without synchronization, multiple processes may access the shared data simultaneously and create race conditions or inconsistent data.

Semaphores are used to achieve synchronization between readers and writers.

Generally two semaphores are used:

  • mutex → Protects reader count.
  • writeblock → Controls writer access.

A variable called readcount is maintained to track the number of readers currently accessing the shared resource.

When the first reader enters, it blocks writers from entering. When the last reader exits, writers are allowed to access the shared resource again.

This solution ensures:

  • Concurrent access for multiple readers.
  • Exclusive access for writers.
  • Prevention of race conditions.

Program


#include <stdio.h>
#include <pthread.h>
#include <semaphore.h>
#include <unistd.h>

sem_t mutex, writeblock;

int data = 0;

int readcount = 0;

void *reader(void *arg)
{
    int id = *(int *)arg;

    sem_wait(&mutex);

    readcount++;

    if(readcount == 1)
    {
        sem_wait(&writeblock);
    }

    sem_post(&mutex);

    printf("Reader %d is reading data = %d\\n", id, data);

    sleep(1);

    sem_wait(&mutex);

    readcount--;

    if(readcount == 0)
    {
        sem_post(&writeblock);
    }

    sem_post(&mutex);

    return NULL;
}

void *writer(void *arg)
{
    int id = *(int *)arg;

    sem_wait(&writeblock);

    data++;

    printf("Writer %d is writing data = %d\\n", id, data);

    sleep(1);

    sem_post(&writeblock);

    return NULL;
}

int main()
{
    pthread_t r1, r2, w1;

    int id1 = 1;
    int id2 = 2;
    int id3 = 1;

    sem_init(&mutex, 0, 1);

    sem_init(&writeblock, 0, 1);

    pthread_create(&r1, NULL, reader, &id1);

    pthread_create(&r2, NULL, reader, &id2);

    pthread_create(&w1, NULL, writer, &id3);

    pthread_join(r1, NULL);

    pthread_join(r2, NULL);

    pthread_join(w1, NULL);

    sem_destroy(&mutex);

    sem_destroy(&writeblock);

    return 0;
}

Output

Reader 1 is reading data = 0 Reader 2 is reading data = 0 Writer 1 is writing data = 1

Conclusion

Thus the Reader Writer Problem using Semaphores was implemented successfully.

Semaphores help in synchronization between multiple processes and prevent race conditions while accessing shared resources.
