Practical 01

Study of Window
Task Manager

Aim

To study Window Task Manager by exploring various tools such as Applications, Processes, Services, Networking and Performance.

Theory

Windows Task Manager is a system monitoring and management utility provided by the Microsoft Windows Operating System. It allows users to view and control running applications, background processes, system services and hardware resource usage.

Task Manager provides real time information about system CPU usage, memory consumption, disk activity and network performance. It also enables users to terminate unresponsive applications, start new tasks and manage startup programs.

If any application becomes unresponsive or consumes excessive system resources, Task Manager provides an option to terminate the application safely. This feature is useful when a system becomes slow or frozen due to malfunctioning software.

Applications consume system resources such as CPU time, memory and disk access. By observing application behaviour in Task Manager, users can analyse how different programs impact system performance.

Processes Tab

A process is an instance of a running program. Every application running on a system consists of one or more processes. In addition to user initiated applications, the operating system runs multiple background processes to support system functionality.

The Processes section in Task Manager displays all running processes along with their resource usage including CPU, memory, disk and network consumption.

This information helps in identifying processes that are consuming excessive resources and may cause system slowdown.

Processes are categorized into application processes, background processes and system processes. Background processes support system operations while system processes are critical for operating system stability.

Services Tab

Services are special types of programs that run in the background without direct user interaction. They usually start automatically when the operating system boots and continue running to support essential system functions such as networking, security, printing and updates.

The Services tab in Task Manager displays a list of all system services along with their current status such as running or stopped.

Managing services is an important task because Task Manager allows users to start, stop or restart services whenever required.

Understanding system services helps engineers diagnose system issues, optimize performance and maintain system reliability.

Performance Tab

The Performance section of Windows Task Manager provides a graphical representation of system resource usage in real time.

This section displays performance metrics for CPU, memory, disk and network. CPU performance shows processor usage, number of cores and processing speed.

Memory performance indicates total installed RAM, used memory and available memory. Disk performance provides information about read and write speeds while network performance shows data transfer rates.

Performance monitoring helps in identifying system bottlenecks and understanding how workloads affect system behaviour.

Networking Tab

Networking refers to communication between computer systems and other devices over a network.

The Networking tool in Task Manager provides details about network adapters and their current usage.

It shows real time data such as network speed, utilization percentage and data sent or received. This information helps users analyse network performance and detect unusual network activity.

Importance

Windows Task Manager is an essential utility for understanding operating system behaviour. It provides transparency into how system resources are allocated and used by applications and processes.

Conclusion

Hence successfully understood the concept of Task Manager tools like Applications, Processes, Networking, Performance and their importance in the Operating System.
