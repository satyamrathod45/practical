CPU Scheduling
Algorithms

Aim

To study and implement CPU Scheduling Algorithms using FCFS and Round Robin.

Theory

CPU Scheduling is the process used by the operating system to decide which process gets CPU execution time.

Scheduling algorithms improve system performance and CPU utilization.

FCFS Scheduling

FCFS (First Come First Serve) is a non-preemptive scheduling algorithm.

In this algorithm, the process which arrives first gets executed first.

  • Simple and easy to implement.
  • Processes are executed in arrival order.
  • May cause large waiting time.

FCFS Program


#include <stdio.h>

int main()
{
    int n, i;

    printf("Enter number of processes: ");
    scanf("%d", &n);

    int bt[n], wt[n], tat[n];

    printf("Enter Burst Time:\\n");

    for(i = 0; i < n; i++)
    {
        printf("P%d: ", i + 1);
        scanf("%d", &bt[i]);
    }

    wt[0] = 0;

    for(i = 1; i < n; i++)
    {
        wt[i] = wt[i - 1] + bt[i - 1];
    }

    for(i = 0; i < n; i++)
    {
        tat[i] = wt[i] + bt[i];
    }

    printf("\\nProcess\\tBT\\tWT\\tTAT\\n");

    for(i = 0; i < n; i++)
    {
        printf("P%d\\t%d\\t%d\\t%d\\n",
        i + 1,
        bt[i],
        wt[i],
        tat[i]);
    }

    return 0;
}

Round Robin Scheduling

Round Robin is a preemptive CPU scheduling algorithm.

Each process gets a fixed time quantum for execution. After the time quantum, the process moves to the end of queue if it is not completed.

  • Fair scheduling technique.
  • Used in time-sharing systems.
  • Reduces starvation problem.

Round Robin Program


#include <stdio.h>

int main()
{
    int n, tq, i;
    
    printf("Enter number of processes: ");
    scanf("%d", &n);

    int bt[n], rem[n], wt[n], tat[n];

    printf("Enter Burst Time:\\n");

    for(i = 0; i < n; i++)
    {
        printf("P%d: ", i + 1);
        scanf("%d", &bt[i]);

        rem[i] = bt[i];
    }

    printf("Enter Time Quantum: ");
    scanf("%d", &tq);

    int time = 0;
    int done;

    do
    {
        done = 1;

        for(i = 0; i < n; i++)
        {
            if(rem[i] > 0)
            {
                done = 0;

                if(rem[i] > tq)
                {
                    time += tq;
                    rem[i] -= tq;
                }

                else
                {
                    time += rem[i];

                    wt[i] = time - bt[i];

                    rem[i] = 0;

                    tat[i] = wt[i] + bt[i];
                }
            }
        }

    } while(done == 0);

    printf("\\nProcess\\tBT\\tWT\\tTAT\\n");

    for(i = 0; i < n; i++)
    {
        printf("P%d\\t%d\\t%d\\t%d\\n",
        i + 1,
        bt[i],
        wt[i],
        tat[i]);
    }

    return 0;
}
