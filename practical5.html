Inter Process
Communication

Aim

To write a program for Inter Process Communication using Shared Memory and Pipes in Linux Operating System.

Theory

Inter Process Communication (IPC) is a mechanism that allows two or more processes to communicate and exchange data with each other.

In an operating system, processes normally execute independently and have separate memory spaces. IPC provides a way for processes to share information and coordinate their execution efficiently.

IPC is very important in modern operating systems because multiple applications and services need to interact with each other while running simultaneously.

Inter Process Communication helps in:

  • Data sharing between processes.
  • Synchronization between tasks.
  • Resource sharing and coordination.
  • Communication between parent and child processes.

Pipe Communication

A Pipe is one of the simplest IPC mechanisms used in Unix and Linux.

It creates a unidirectional communication channel between related processes such as parent and child processes.

One process writes data into the pipe while the other process reads the data from the pipe.

Pipe uses two file descriptors:

  • fd[0] → Read End
  • fd[1] → Write End

Program using Pipe


#include <stdio.h>
#include <unistd.h>
#include <string.h>

int main()
{
    int fd[2];

    char write_msg[] = "Hello from Parent Process";

    char read_msg[100];

    pipe(fd);

    if(fork() == 0)
    {
        close(fd[1]);

        read(fd[0], read_msg, sizeof(read_msg));

        printf("Child Process Received: %s\\n", read_msg);

        close(fd[0]);
    }

    else
    {
        close(fd[0]);

        write(fd[1], write_msg, strlen(write_msg) + 1);

        printf("Parent Process Sent Message\\n");

        close(fd[1]);
    }

    return 0;
}

Shared Memory

Shared Memory is the fastest Inter Process Communication method.

In this method, multiple processes access the same memory segment for communication and data exchange.

A memory block is created by one process and other processes attach to the same block to read or write data.

Since processes directly access the shared memory, communication becomes very fast and efficient.

Important system calls used in shared memory are:

  • shmget()
  • shmat()
  • shmdt()
  • shmctl()

Program using Shared Memory


#include <stdio.h>
#include <sys/ipc.h>
#include <sys/shm.h>
#include <string.h>

int main()
{
    int shmid;

    char *str;

    shmid = shmget((key_t)1122, 1024, 0666 | IPC_CREAT);

    str = (char*) shmat(shmid, NULL, 0);

    printf("Write Data: ");

    gets(str);

    printf("Data Written in Memory: %s\\n", str);

    shmdt(str);

    return 0;
}

Output

Parent Process Sent Message Child Process Received: Hello from Parent Process Write Data: Hello IPC Data Written in Memory: Hello IPC
