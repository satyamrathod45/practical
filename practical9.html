Banker’s Algorithm
for Deadlock
Avoidance

Aim

To write a program to simulate Banker’s Algorithm for Deadlock Avoidance in Operating System.

Theory

Banker’s Algorithm is a deadlock avoidance algorithm used by the Operating System to allocate resources safely among processes.

The algorithm checks whether granting a resource request keeps the system in a safe state before allocation is performed.

A safe state means the system can allocate resources to all processes in some order without causing deadlock.

Banker’s Algorithm works by comparing:

  • Available Resources
  • Maximum Resources needed by each process
  • Allocated Resources
  • Need Matrix = Max - Allocation

A process is executed only if its remaining need is less than or equal to the available resources.

After execution, allocated resources are released back to the system.

Working of Banker’s Algorithm:

  • Calculate the Need Matrix.
  • Find processes whose need is less than available resources.
  • Allocate resources temporarily and execute the process.
  • Release resources after process completion.
  • Repeat until all processes finish or no safe sequence exists.

Advantages of Banker’s Algorithm:

  • Prevents deadlock before it occurs.
  • Ensures safe resource allocation.

Disadvantages of Banker’s Algorithm:

  • Requires prior knowledge of maximum resource needs.
  • Complex for large systems.

Program


#include <stdio.h>

int main()
{
    int n = 5;

    int m = 3;

    int i, j, k;

    int allocation[5][3] =
    {
        {0, 1, 0},
        {2, 0, 0},
        {3, 0, 2},
        {2, 1, 1},
        {0, 0, 2}
    };

    int max[5][3] =
    {
        {7, 5, 3},
        {3, 2, 2},
        {9, 0, 2},
        {2, 2, 2},
        {4, 3, 3}
    };

    int available[3] = {3, 3, 2};

    int need[5][3];

    for(i = 0; i < n; i++)
    {
        for(j = 0; j < m; j++)
        {
            need[i][j] =
            max[i][j] - allocation[i][j];
        }
    }

    int finish[5] = {0};

    int safeSequence[5];

    int count = 0;

    while(count < n)
    {
        int found = 0;

        for(i = 0; i < n; i++)
        {
            if(finish[i] == 0)
            {
                int possible = 1;

                for(j = 0; j < m; j++)
                {
                    if(need[i][j] > available[j])
                    {
                        possible = 0;

                        break;
                    }
                }

                if(possible)
                {
                    for(k = 0; k < m; k++)
                    {
                        available[k] +=
                        allocation[i][k];
                    }

                    safeSequence[count] = i;

                    count++;

                    finish[i] = 1;

                    found = 1;
                }
            }
        }

        if(found == 0)
        {
            break;
        }
    }

    if(count == n)
    {
        printf("System is in Safe State\\n");

        printf("Safe Sequence: ");

        for(i = 0; i < n; i++)
        {
            printf("P%d ", safeSequence[i]);
        }

        printf("\\n");
    }

    else
    {
        printf("System is NOT in Safe State\\n");
    }

    return 0;
}

Output

System is in Safe State Safe Sequence: P1 P3 P4 P0 P2

Conclusion

Thus Banker’s Algorithm was implemented successfully for Deadlock Avoidance.

The algorithm checks safe resource allocation and helps avoid deadlock situations in Operating Systems.
