Practical 03

Creation of Child
Process using fork()

Aim

Write a program that illustrates the creation of child process using fork() system call. Parent and child processes perform different tasks.

Theory

The fork() system call is used in Unix and Linux operating systems to create a new process called a child process.

When fork() is executed:

  • A new child process is created.
  • The child process is an exact copy of parent process.
  • Both processes continue execution independently.

Program


#include <stdio.h>
#include <unistd.h>

int main()
{
    pid_t pid;

    pid = fork();

    if (pid < 0)
    {
        printf(
            "Fork Failed\n"
        );
    }

    else if (pid == 0)
    {
        printf(
            "Child Process\n"
        );

        printf(
            "Child PID = %d\n",
            getpid()
        );

        printf(
            "Parent PID = %d\n",
            getppid()
        );
    }

    else
    {
        printf(
            "Parent Process\n"
        );

        printf(
            "Parent PID = %d\n",
            getpid()
        );

        printf(
            "Child PID = %d\n",
            pid
        );
    }

    return 0;
}

Output

Parent Process Parent PID = 1234 Child PID = 1235 Child Process Child PID = 1235 Parent PID = 1234

Conclusion

Thus the fork() system call was successfully used to create a child process from a parent process.
