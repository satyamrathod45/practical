Practical 02

Advanced Linux
Shell Commands

Aim

Study of Advanced Linux shell commands related to process management, memory management, networking etc.

Theory

Linux shell commands are used to interact with the operating system through the terminal. These commands help users manage files, processes, memory, networking, permissions and system resources efficiently.

Advanced Linux commands are useful for system administration, troubleshooting, performance monitoring and network analysis.

File and Directory Commands

  • ls → List files and directories
  • pwd → Display current working directory
  • cd → Change directory
  • rm → Remove file or directory
  • mkdir → Create new directory
  • cp → Copy files
  • mv → Move files
  • find → Search files by name
  • touch → Create empty file

Process Management Commands

  • ps aux → Display active processes
  • top / htop → Real time process monitoring
  • kill <PID> → Terminate process using PID
  • killall → Kill all instances of a process
  • pkill → Terminate process by pattern
  • nice → Run command with priority
  • renice → Change process priority
  • bg / fg → Background and foreground process control
  • nohup → Run command immune to hangup
localhost:~/practical2# ps PID USER TIME COMMAND 1 root 0:01 {init} /bin/sh /sbin/init 2 root 0:00 [kthreadd] 3 root 0:00 [kworker/0:0] localhost:~/practical2# renice 5 -p 1 1 (process ID) old priority 5, new priority 5

Memory Management Commands

  • free -M → Display memory usage in MB
  • vmstat → Report memory and CPU statistics
  • top / htop → Monitor memory usage in real time
  • sync → Write cached data to disk
  • echo 3 → Clear cache memory
  • ulimit -a → Display user resource limits

Networking Commands

  • ifconfig / ip a → Display network interface details
  • ping → Check network connectivity
  • netstat -tulnp → List active connections
  • ss -tulnp → Display socket statistics
  • traceroute → Trace route packets
  • nslookup / dig → DNS query commands
  • curl → Fetch HTTP data
  • wget → Download files from internet
  • iptables -L → Display firewall rules
localhost:~# ping 127.0.0.1 64 bytes from 127.0.0.1: seq=0 ttl=64 time=0.800 ms 64 bytes from 127.0.0.1: seq=1 ttl=64 time=1.400 ms localhost:~# traceroute 127.0.0.1 1 localhost (127.0.0.1)

File Permission and Ownership

  • chmod → Change file permissions
  • chown → Change file owner and group
  • ls -l → Display file permissions
  • umask → Set default permissions

User Management Commands

  • who → Show logged in users
  • whoami → Display current user
  • adduser → Add new user
  • passwd → Change user password
  • deluser → Delete user
  • groups → Show user groups

Disk Management Commands

  • df -h → Show disk space usage
  • du -sh → Display directory size
  • mount → Mount file system
  • umount → Unmount file system
  • fdisk -l → List partition tables

Conclusion

Hence successfully studied advanced Linux shell commands related to process management, memory management, networking, file permissions, user management and disk management.

🐧 Observation: Linux shell commands help users efficiently manage processes, monitor memory, configure networking and control system resources directly from the terminal.
